# AI Evaluation Portfolio

A practical portfolio demonstrating experience in AI evaluation, AI safety, mathematical reasoning, data analytics, frontend development, and quality assurance.

## Areas Covered

- AI response evaluation
- AI safety assessment
- Mathematical reasoning evaluation
- Data analytics
- Python scripting
- HTML, CSS, and JavaScript
- Frontend dashboards
- Rubric-based quality assurance

## Repository Structure

- `ai_safety/` — AI safety rubrics and evaluation examples
- `data_analytics/` — Data analysis scripts and sample datasets
- `docs/` — Project documentation
- `frontend_dashboard/` — HTML, CSS, and JavaScript dashboard
- `math_evaluation/` — Mathematics reasoning evaluation examples
- `tests/` — Python tests

## Technical Skills

Python, JavaScript, HTML, CSS, React, SQL, SPSS, Excel, JSON, Markdown, Git, GitHub, AI Safety, LLM Evaluation, Prompt Evaluation, and Data Analytics.

## Purpose

This repository presents independent, non-proprietary examples of AI evaluation workflows. It does not contain confidential client tasks or restricted project materials.
